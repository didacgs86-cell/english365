# English365 v2

Navegación por ocho categorías de vocabulario, modos de práctica contextualizados, gramática B2 y repaso espaciado.

**Importante:** Exporta tu progreso antes de actualizar. Se mantiene la clave local `english365_progress_v1` y los IDs originales de las 64 tarjetas.

Sube los archivos a la raíz del repositorio y activa GitHub Pages. La importación sustituye los datos locales; no combina historiales.

La selección temática permite que algunas palabras aparezcan en más de una categoría. El contenido es el mismo banco inicial de 64 tarjetas; no se han inventado cientos de entradas.
